## 一、Go 后端服务 (`server/`)

专为 2核2G Linux/CentOS 场景设计的异步转写调度后端。

### 1. 架构与目录结构

```
server/
├── cmd/server/main.go          # 服务入口与优雅停机
├── config.example.yaml         # 配置文件示例 (端口, Whisper 地址, 上传与队列参数)
├── go.mod / go.sum             # Go 依赖 (Gin, CORS, UUID, YAML)
├── internal/
│   ├── api/                    # HTTP 路由、Handler、RequestID/CORS/日志中间件
│   │   ├── handler.go
│   │   ├── middleware.go
│   │   ├── router.go
│   │   └── api_test.go
│   ├── audio/                  # FFmpeg 自动转码封装 (16kHz 单声道 WAV)
│   │   └── converter.go
│   ├── config/                 # 配置加载与环境变量解析
│   │   └── config.go
│   ├── model/                  # 接口入参、出参、错误码、Task 领域模型
│   │   ├── response.go
│   │   └── task.go
│   ├── queue/                  # 串行任务队列与单 Worker (严格防并发 OOM)
│   │   └── queue.go
│   ├── service/                # 业务逻辑编排 (文件存储、入队、任务查询、健康检查)
│   │   └── transcribe.go
│   ├── store/                  # 线程安全任务存储 (已实现 MemoryStore，可扩展 SQLite/MySQL)
│   │   └── store.go
│   └── whisper/                # whisper-server HTTP 客户端封装 (/inference)
│       └── client.go
└── README.md
```

### 2. 实现的 API

| 方法 | 接口路径 | 说明 |
|---|---|---|
| `GET` | `/api/health` | 服务健康检查及 whisper-server 连通状态 |
| `POST` | `/api/transcribe` | 上传音频文件并创建异步转写任务（返回 `task_id`，状态 `queued`） |
| `GET` | `/api/transcribe/:task_id` | 轮询/查询任务转写状态、文本结果、错误信息及耗时 |
| `GET` | `/api/tasks` | 查询转写任务历史列表 |

### 3. 运行与验证

```bash
cd server
go test ./...       # 自动化测试已全部通过 (ok huawei-whisper-server/internal/api)
go run ./cmd/server/main.go
```

### 2. 核心特性

1. **三种音频输入渠道**：
   - 应用内现场直录：直接录制为 16kHz 单声道 WAV，直通 Whisper 无需转码。
   - 华为系统录音机分享接收：录音机内点击“分享”选择本 App，自动调起并上传。
   - 外部音频文件选择导入：支持 WAV, MP3, M4A, AAC, FLAC 等。
2. **异步轮询引擎**：上传完成后自动触发 2 秒间隔的状态轮询，实时流转 `queued -> processing -> success / failed`。
3. **设置中心**：支持随时在 UI 中配置 Go 服务端地址并一键测试后端及 whisper 的健康状态。
